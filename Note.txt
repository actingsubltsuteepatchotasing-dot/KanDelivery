 # Deployment  = OK (Vercel + Next.js พร้อม deploy แล้ว)
 - ใช้ Vercel + Next.js 15 (App Router) รันบน Vercel เท่านั้น
 - "ไม่ต้องติดตั้งอะไรทั้งสิ้น" = ในเครื่องเราไม่ต้องลงอะไรเลย
   ไม่ต้องลง Node.js ไม่ต้องรัน npm install ไม่ต้อง build เอง
   เพราะ Vercel จะรัน npm install + next build ให้เองบนคลาวด์
 - vercel.json ระบุ framework = nextjs ไว้แล้ว (Vercel ตั้งค่าที่เหลือให้เอง)
 - .vercelignore กัน Note.txt / CLAUDE.md / legacy/ ไม่ให้ขึ้นเว็บสาธารณะ

 วิธี deploy (เลือกอย่างใดอย่างหนึ่ง)
 A. ลากโฟลเดอร์: เข้า vercel.com -> Add New -> Project -> Deploy
    ลากโฟลเดอร์นี้ทั้งโฟลเดอร์ลงไป (ไม่ต้องลาก node_modules เพราะไม่มี)
    -> Vercel ตรวจเจอ Next.js เอง -> Deploy -> ได้ URL ใช้งานทันที
 B. ผ่าน Git: push โฟลเดอร์นี้ขึ้น GitHub -> Import Project ใน Vercel
    -> Framework Preset ขึ้นเป็น "Next.js" อยู่แล้ว -> Deploy
    -> หลังจากนี้แค่ push ใหม่ Vercel จะ build + อัปเดตเว็บให้อัตโนมัติ
 * เวลา build ครั้งแรกประมาณ 1-2 นาที
 * ห้ามอัปโฟลเดอร์ node_modules / .next ขึ้นไป (มี .gitignore กันไว้แล้ว)

 ถ้าอยากแก้โค้ดแล้วลองรันในเครื่อง (ทำหรือไม่ทำก็ได้ ไม่จำเป็น)
   ต้องมี Node.js -> npm install -> npm run dev -> เปิด localhost:3000
